## 关键验收证据

- 小白X 3.2.5 的普通代码块与流式模板源码均使用 `.xiaobaix-iframe`；改动前对应模拟页面不被识别，改动后可与酒馆助手前端共存。已有页面、动态 Blob、按钮和输入框、开关恢复均通过。
- 81 次模拟 `updateTemplateVariables` 更新后，变量文本及动态白底选项正确显示，同源嵌套页面继续处理，宿主只启动时全扫一次；移除标识、导航和删除容器后清理本插件实例。
- 无渲染标识的同名前缀 iframe 和后台脚本 iframe 不处理；跨域、沙箱、CSP 及其他引擎分别跳过，正常小白X模拟前端不受影响。该测试模拟渲染 DOM 和回调，未加载小白X完整插件。

- 新版和 1.14.0 加载器模拟下，设置默认收起但配色按已保存的开关继续运行；展开／收起不切换开关、不触发保存，也不进入宿主的抽屉委托处理。刷新后恢复收起状态并保留启用设置。
- Enter／空格可操作标题，Tab 可进入展开后的开关；收起后的隐藏开关不进入键盘焦点顺序。390px 窄屏无横向溢出，桌面与窄屏截图已复查。

- 1.14.0 的模块脚本加载器模拟不调用生命周期钩子，仍可启动并处理已有／动态前端；开关即时恢复、刷新保存和禁用后不加载均通过。仅为新版清理钩子导入模块时保持未启动，立即停用也能取消排队的启动。版本源码依据与实际边界见 [COMPATIBILITY.md](COMPATIBILITY.md)。

- 白底、行内 `!important`、渐变和动态选项均变暗；样本普通面板及渐变背景上的文字对比度达到 4.5:1。
- 图片及不透明 CSS 背景图片的采样截图像素在转换前后相同；Canvas 像素不变，图片／视频／Canvas 的滤镜为 `none`。
- 背景图片与渐变叠加时保留原图片 URL，只转换渐变；行内图片声明同样不进入图片读取、分析或反色路径。
- 隔离的混合图片区域保留作者背景、伪元素及滤镜；同位置的图片区域采样截图在开关前后保持一致（渐变抖动误差上限为单通道 2/255，作者样式值严格相等），旁边的白色阅读面板仍变暗。动态新增、行内 `!important` 及关闭后属性清理同样通过。
- 反复开关后恢复作者颜色和重要性，清掉引擎标记、附加变量与脚本；运行中作者修改的颜色、圆角和普通优先级保留。
- Blob、srcdoc、同源嵌套页面、iframe 导航、聊天容器替换、后赋值的 iframe 标识均通过。
- 流式新增内容、思考折叠区、弹窗、按钮、输入框、选择框和文本框保持可用。
- 跨域、受限沙箱、脚本／样式 CSP 拦截及已有其他配色引擎的情况分别跳过；其他前端继续工作。
- 延迟脚本到达、关闭后再启用、连续生命周期调用不会重复挂载或重新激活已关闭的配色。
- 6 个前端、120 次文本更新的样本中，宿主只在启动时全扫一次，没有重复注入。
- 窄屏样本的长内容可在 iframe 内纵向滚动；测试和截图不把桌面／窄屏模拟当作手机实机证据。

构建适配的原因与边界见 [DARKREADER-PATCH.md](DARKREADER-PATCH.md)。适配不修改原始 npm 依赖文件，源码锚点变化或适配未接入时构建会失败。

截图稳定性补充：完整回归发现原有混合图片样本的严格 PNG 比较会偶发失败；解码检查的最大差异为单通道 2/255。因此只对该渐变合成样本采用有界像素误差，未放宽普通图片或不透明背景图片的原有严格比较，也未改变配色引擎。0.1.2 修正后该 Chromium 用例连续独立运行 10 次均通过；0.1.3 与本次 0.1.4 的完整回归也再次通过。

## 真实酒馆只读诊断与待验收

用户提供的浏览器“查看源代码”保存页没有运行时前端，因此另行只读检查了已打开的酒馆前端。观察到头像使用 `mix-blend-mode: multiply`，其隔离容器带有浅色渐变及伪元素叠层；容器变暗会连带压暗图片。这一合成方式已用不含用户内容的模拟样本在 Nightveil 中复现并通过修复回归。

受检页面中存在其他 Dark Reader 实例标记，未发现 Nightveil 设置面板或本插件拥有的运行时脚本。因此，这次只读观察不能证明该页面由 Nightveil 管理，也不能当作本修复版的真实安装验收。未修改该酒馆的设置、内容或加载状态；手机浏览器的强制深色与扩展共存情况仍待确认。用户保存页、截图、图片及聊天文本均未加入项目或上传仓库。

最低宿主源码基线已核对 SillyTavern 1.14.0（`9c9be90`），保留原 1.19.0（`7e8663c`）、酒馆助手 4.12.1（`91a706c`）和小白X 3.2.5（`707e03f`）的参考基线；并未因此宣称两种渲染插件本身均兼容酒馆 1.14.0。尚无目标 1.14.0 实例的安装快照，故未把模拟能力清单当作 installed-snapshot，也未声称真实宿主能力检查已通过。

在目标 1.14.0 实例中仍需核验：扩展管理器识别与启停、真实设置保存与重载、账号及聊天切换、普通／流式前端与 Blob 模式、小白X自动高度和变量桥接／消息通道、角色卡脚本交互、现用主题及浏览器扩展共存、卸载清理，以及实际手机浏览器表现。

已知限制：跨域或受限页面无法处理；不可读外部 CSS 可局部保留原色；闭合 Shadow DOM、部分封装组件和特殊绘图不保证转换；初次加载可能短暂显示原色；自动算法可能轻微调整已有暗色与强调色。
